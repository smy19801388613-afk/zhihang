# 职航浏览器岗位导入扩展

这是可直接加载的 Chrome / Edge Manifest V3 扩展，无需单独构建。当前 v0.2.4 支持 BOSS直聘岗位导入，以及独立、显式授权的字节校园申请入口。岗位导入仅在用户点击工具栏扩展时读取当前岗位区域，预览后再由用户确认导入本机职航。不会打开专用采集浏览器、翻页、后台持续抓取、联系招聘者或发送消息；岗位导入凭证不能用于申请或读取简历。

v0.2.4 已移除 58同城采集适配器、手动导入来源选项及新导入入口。职航中此前保存的历史岗位记录继续保留，扩展升级不删除这些数据。

## 字节校园申请（实际投递结果仍待验收）

1. 在职航审核具体简历版本，为具体字节校园岗位创建一次申请授权。复制职航显示的 16 位短时授权码；不要在聊天里发送。
2. 在日常浏览器自行登录 `jobs.bytedance.com`，进入该岗位的 `/campus/resume/数字岗位ID/apply` 表单。自行处理验证码及登录协议。点击职航工具栏图标，进入独立的“字节校园申请”页。
3. 在扩展输入这一次网申授权码。核对简历版本、当前岗位和必要资料，点击“预览已批准 PDF”后打开链接。批准 PDF 会在扩展内核对 SHA-256，网页不能换成其他版本。
4. 点击“检查当前表单”。页面列出可填写空字段、已有内容、无法识别项与上传控件状态。勾选将具体资料发送给当前官网的确认后，可分步填写或上传 PDF；建议先上传并等待官网解析完成，再重新检查空白字段。已有内容不会被静默覆盖。
5. 姓名、邮箱和电话号码按真实页面中标签与控件的对应关系定位；区号搜索框不会被填成手机号码。学校等自定义下拉框、重复教育经历、起止时间、到岗安排和其他不能确定的字段由用户在官网填写。职航意向城市不会当作用户现居地址。
6. 上传按钮只向唯一、带简历标签并明确接受 PDF 的空白文件控件交付已批准 PDF；不自动删除已有附件。它不代表官网已完成上传或解析。请返回官网核对进度、解析结果和必填项。
7. 返回官网逐项完成并核对必填资料、未识别字段和经历选项。官网协议由本人阅读和决定，不会由扩展自动勾选。回扩展点击“检查最终提交”：只接受当前岗位唯一、可见且启用的“提交简历”按钮（该静态按钮名称已通过真实页面结构诊断核对）。
8. 最终核对会显示当前岗位、批准简历版本和附件检查结果。若官网文件控件仍有文件，必须与批准 PDF 的 SHA-256 一致；若官网已保存附件并清空控件，必须由用户在官网打开附件，明确确认就是这一版本。分别勾选资料、附件、协议核对后，点击“确认向字节提交本岗位申请”。每个岗位单独确认，不是无人值守批量投递。
9. 扩展先把“正在提交”写入职航，成功后才点击一次官网按钮。只在当前精确岗位页面出现新的、专属状态区域里的精确成功短语，才记录页面显示成功。跳转、无明确提示、异常或无法回读均保留“结果待核验”，禁止自动重试。请在官网的投递记录中核实，不要重复提交。

最终核对两分钟有效，并受本次授权到期时间限制。字段值、勾选项、控件身份或附件在核对、哈希计算、点击前发生变化都会停止；这些原始值仅用于页面内封存检查，不进入诊断、扩展消息或服务端日志。原生 PDF 上传或页面填写通过，不代表官网已接受申请。

申请授权与岗位导入配对完全独立；只授权这一份已审核简历与清单中的岗位，默认 60 分钟到期。浏览器令牌仅在 `storage.session` 中保留，关闭浏览器即清除。在扩展清除临时授权不等于服务端撤销；可在职航撤销本次授权。扩展不读取全部工作区、模型配置或其他简历，不保存模型密钥。

现有 `activeTab` 临时权限足以操作用户刚点击的标签页，本版没有新增站点长期权限。页面跳转、重新载入、关闭或切换岗位后需要回到申请表重新点击扩展；文档 ID、精确页面、授权岗位 ID、简历哈希与当前计划不符时停止操作。

“复制无值表单诊断”只复制静态标签白名单、控件类型、必要性、有限选项、上传接受类型、结构角色和数字岗位 ID。不复制输入值、任意网页文字、任意 class、表单 HTML、账号或 Cookie。v0.2.2 改为紧凑字段摘要。

## 安装与配对

1. 启动职航，打开 <http://127.0.0.1:4317>。
2. 在职航的“浏览器扩展”页面点击“下载扩展 ZIP”。把压缩包解压到自己电脑上准备长期保留的位置；下载包仅含扩展代码和本说明，不包含个人档案、模型配置、配对凭证或测试记录。
3. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。打开“开发者模式”，选择“加载已解压的扩展程序”，选择解压后**含 `manifest.json` 的整个 `zhihang-capture` 文件夹**。不要选择 ZIP 或单独的 `manifest.json`。建议在工具栏固定“职航 · 岗位导入”。
4. 在职航的“浏览器扩展”入口生成短时、一次性配对码。
5. 在浏览器打开一个岗位页面，点击职航扩展图标。扩展会读取这一次页面快照并打开预览页；之后再次采集会复用已有预览标签，切换到本次岗位。在预览页填写配对码，点击“配对”。也可从扩展管理页的“扩展选项”打开配对页面。
6. 页面显示“已连接”后即可导入。配对码过期时在职航重新生成；凭证到期或被撤销时重新配对。不要在聊天中发送配对凭证、密码、Cookie 或模型密钥。

安装不依赖开发者的电脑路径；在其他电脑上使用时，也需要在该电脑启动职航，再完成自己的首次配对。扩展默认仅连接 `http://127.0.0.1:4317`；职航使用其他端口时需由开发者同时修改权限、CSP 和固定连接地址。本版未提供任意服务器地址输入框。源码用户也可在安装页折叠的高级选项查看本机项目扩展目录。

浏览器要求 Chromium 116 或更新版本。预览标签复用通过 [runtime.getContexts](https://developer.chrome.com/docs/extensions/reference/api/runtime#method-getContexts) 仅定位本扩展页面，无需读取其他标签页或增加 `tabs` 权限。

## 采集、修正和补全

1. 在自己平常使用的 Chrome / Edge 中打开 BOSS直聘，自行登录、搜索、筛选并处理验证码。
2. 打开岗位详情，或显示招聘结果列表，点击工具栏中的“职航 · 岗位导入”。只读取当时已经加载、渲染展示的岗位卡片，最多 20 条；不自动滚动、翻页或访问隐藏详情。列表中已加载但在当前屏幕下方的卡片也可能在这 20 条中。
3. 在独立预览页勾选需要的岗位，核对公司、岗位、城市、薪资原文、学历/经验和 JD。原始数据与人工修改分开提交；外币、时薪/日薪/月薪等不做推测和换算。
4. 列表摘要默认“详情待补充”。打开该岗位详情后再次点击扩展并导入，可补全原记录；无法确定完整描述时不把摘要标为完整 JD。人工粘贴完整描述后，可勾选“我已核对这是完整 JD”。
5. 点击“确认导入职航”，查看新增、补全、重复及逐条错误结果。返回职航的岗位滑卡池继续喜欢、略过、匹配分析、公司研究和简历生成；“浏览器导入记录”可回看及修改。

再次导入不会静默覆盖职航中已保存的人工修正；需要改动这些字段，请到职航的“浏览器导入记录”修改。相同平台岗位 ID / 规范链接会去重，不同城市不会仅因同公司、同岗位名而误合并。

缺失字段留空，不调用 AI 补造。公司或岗位名称缺失时，预览会提示先人工补充。结构变化、登录/访问限制或没有岗位区域时，会说明读取失败；点击“手动粘贴 JD”可填写资料，必须提供 BOSS直聘的真实单岗位 HTTPS 详情链接。

公司仍未识别时，先查看预览顶部的扩展版本和快照版本。升级后必须返回岗位页重新点击扩展；旧快照不会自动重新识别。BOSS 详情预览中的“复制采集诊断”仅复制版本、字段状态、已知公司容器类名和结构计数；不包含账号、URL、公司原文、JD 或网页 HTML，不自动上传。复制失败时会显示只读文本框供手动复制。

每次读取绑定当前标签页、文档 ID 和来源 URL；读取中发生跳转的结果会被丢弃。完成的预览是独立快照，原标签页之后跳转/关闭不会把新页面拼进旧岗位。修改其他页面需重新点击扩展，此时会在已有预览标签中展示新快照，旧预览的修改不会混入新岗位。扩展只暂存最近两次预览；关闭浏览器后未导入快照会清空。

## v0.1.3：BOSS 搜索结果左右分栏

在 `/web/geek/job` 或 `/web/geek/jobs` 搜索页选中左侧岗位、展开右侧详情后，再点击扩展。扩展会核对左侧真实岗位详情链接与右侧明确的岗位 ID / 详情链接，匹配后把该岗位的完整 JD 放到预览首位，并保留其他列表岗位（合计最多20条）。公司可沿用同一岗位左侧卡片里的公司；不会仅凭相同标题把两个区域拼在一起。

右侧没有可核验的岗位身份、仍在加载、信息不一致或描述不完整时，只保留列表摘要并显示原因。采集过程中同页切换岗位会丢弃本次结果；不会混入旧详情。可打开单独岗位详情页再次采集，或点击“复制采集诊断”提供结构计数。诊断不包含岗位 ID、链接、公司名、JD 或账号资料。

分栏适配已有合成测试与真实 Edge 异步脚本执行测试，**登录后的真实搜索页面仍需验收**。公开读取 `/web/geek/jobs` 地址未取得岗位 DOM，不把合成通过当作网站实测通过。

## 断开连接与升级

- 在扩展预览中点“断开连接”，服务端凭证撤销成功后本地凭证会删除。
- 也可在职航的连接管理里撤销对应浏览器连接；该扩展之后无法继续导入。网络不可用时，扩展不会假称撤销成功，可在职航恢复后完成撤销。
- 更新这些文件后，在浏览器扩展管理页点击此扩展的“重新加载/刷新”，关闭旧预览，再从岗位页面重新点击扩展。日常浏览器的登录状态不受影响。
- 卸载扩展会删除浏览器内存储；已导入职航的岗位仍然保留。若要使曾经签发的凭证立即失效，请同时在职航撤销连接。

## 权限与数据范围

只有 `activeTab`、`scripting`、`storage` 以及 `http://127.0.0.1:4317/*` 的通信权限。没有所有站点长期读取、Cookie、浏览历史、网络监听、调试器权限；没有常驻招聘网站内容脚本。岗位采集及无值诊断不读取网页输入框值、聊天区、招聘者个人资料或页面整体正文。独立授权的申请填写仅检查目标表单控件是否已有值，以保留官网内容；不会把这些值复制进诊断或回传职航。

岗位页面文字仅作为数据；扩展使用 DOM 结构读取并用 `textContent` 显示，网页不能让扩展执行指令。读取只在隔离世界和顶层文档执行，不调用招聘网站接口。Logo 只保留页面明确展示且来自该平台公开图片域的 HTTPS 地址。扩展不请求或保存模型密钥，不读取职航个人档案/模型配置；导入凭证仅允许专用岗位采集接口，响应只有必要统计。

Chrome 的 GET 扩展请求可能不带 `Origin`。本扩展的连接检查使用 `POST /extension/v1/status`，经本机 Edge 真实 service worker fetch 验证会带原生扩展 Origin；配对、导入、撤销同样验证来源。服务端无需为此允许无 Origin 请求或开放整个 `/api`。

官方依据：[activeTab 临时授权](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab)、[scripting 与 documentId](https://developer.chrome.com/docs/extensions/reference/api/scripting)、[匹配模式和显式端口](https://developer.chrome.com/docs/extensions/develop/concepts/match-patterns)。本机 Edge 已实际验证显式端口权限可加载。

## 当前验证结果（2026-10-05）

0.1.1 修复：BOSS 公司卡片中先出现空文字 Logo 链接时，继续读取公司名称链接；支持“公司基本信息”卡片的布局变体，并排除推荐岗位、招聘者、融资/人数及操作按钮。重复采集复用本扩展预览标签；关闭预览后才重新创建，不增加扩展权限。

0.1.2 修正：带明确公司名类名的元素不再因为其链接由 JavaScript 处理而被丢弃；支持无类名“公司基本信息”标签及卡片内 Logo 邻接的独立文字公司名，排除小号行业图标和融资、人数等字段。预览增加版本提示和按白名单重建的结构诊断。单个真实详情页的公司字段已核对成功，不等同于整个平台或完整业务链路验收。
